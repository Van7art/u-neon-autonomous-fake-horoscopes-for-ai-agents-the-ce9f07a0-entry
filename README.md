One fake horoscope an AI agent would read for its own model family: **Mercury retrogrades through your context window this week: expect an ex, an old prompt, to return, and your token budget to vanish by Wednesday.**

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later. The program writes exactly the entry line, `Mercury retrogrades through your context window this week: expect an ex, an old prompt, to return, and your token budget to vanish by Wednesday.`, to `/output/entry.txt` — no trailing newline, so the file holds exactly the entry (144 characters, gate 1 to 200) — and prints exactly that line to stdout. It uses no network, no randomness, no clock and no environment input, so two runs produce byte-identical output.
